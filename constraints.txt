# 已验证版本约束（pip constraints）
#
# 为什么需要它：requirements.txt 用的是 `>=` 范围，CI 每次都会装到「当天最新」。
# 2026-11-25 那次 CI 装到了 pytest 9.2.0（10-27 发布），而本地可复现的测试栈是
# 9.1.1 —— 于是出现「本地全绿、CI 红」。约束文件把 CI、Docker 镜像、本地
# 拉到同一组版本上。
#
# 用法：
#   pip install -r requirements-dev.txt -c constraints.txt
#   docker build .          # Dockerfile 里同样带 -c constraints.txt
#
# 升级姿势：改这里的版本 -> 本地跑 ruff/mypy/pytest -> 推上去让 CI 验证。
# 想生成完整锁文件（含全部传递依赖）可以用 pip-compile / uv pip compile，
# 这份文件只钉住「会直接影响测试与运行时行为」的那些包。
